Stop synchronization

Cancels active repository transfers and leaves affected repositories marked as errors so they can be retried later. The scheduler and container keep running.

Delete every repository in a destination organization

This calls Gitea’s bulk organization deletion API. It permanently deletes every repository in the selected organization, including repositories not created by GitHarbor. It does not delete the organization itself.

Stop synchronization first. After Gitea finishes the deletion, run a sync to recreate and mirror the GitHarbor destinations.
